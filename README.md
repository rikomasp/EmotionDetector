# Emotion Detector

An AI-based web application that detects emotions in text using IBM Watson NLP.

## Project Structure
- `EmotionDetection/emotion_detection.py` - Core emotion detection logic using Watson NLP
- `EmotionDetection/__init__.py` - Package initializer
- `server.py` - Flask web deployment
- `test_emotion_detection.py` - Unit tests
- `templates/index.html` - Frontend
- `static/mywebscript.js` - Frontend script
